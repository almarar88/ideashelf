# مهامي — منظّم المهام والمواعيد

تطبيق أندرويد أصلي بالعربية لإدارة المهام والمواعيد النهائية، مبني بـ Kotlin و Jetpack Compose.
كل مهامك تبقى على جهازك، ولا تُرسل إلى أي خادم. الإنترنت يُستخدم فقط لعمليات
الشراء والتحقق من الاشتراك عبر Google Play.

هذه النسخة **جاهزة للنشر على متجر جوجل بلاي**: تصغير وتوقيع للإصدار، وحزمة AAB،
وسياسة خصوصية، ونصوص وصور المتجر، ومسار بناء آلي.

## المميزات

### المهام
- عنوان وتفاصيل وملاحظات، وموعد نهائي بتاريخ ووقت، وأولوية وجهة متابعة.
- خطوات فرعية تُحدّث نسبة الإنجاز تلقائياً.
- وسوم حرة، وروابط تُفتح بضغطة، وتثبيت المهام المهمة.
- تكرار يومي أو أسبوعي أو شهري: تُنشأ النسخة التالية تلقائياً عند الإنجاز.
- تأجيل سريع بضغطة (يوم، ثلاثة، أسبوع) مع إمكانية التراجع.
- سجل نشاط لكل مهمة: إنشاء، تعديل، تغيّر حالة، تأجيل، إنجاز.

### المشاريع
- مشاريع ملوّنة لتجميع المهام حسب الجهة أو الملف.
- تصفية القائمة بمشروع واحد، ونسبة إنجاز لكل مشروع.

### القوالب ونماذج الرسائل
- سبعة قوالب مهام جاهزة بخطواتها: اجتماع تنسيقي، تقرير دوري، مخاطبة جهة،
  حصر وثائق، تنظيم دورة تدريبية، متابعة معاملة، مهمة سريعة.
- خمسة نماذج رسائل تُعبَّأ آلياً ببيانات المهمة: تذكير، طلب إفادة رسمي،
  تأكيد موعد، إشعار إنجاز، طلب تمديد — تُنسخ أو تُرسل مباشرة.

### التنبيهات
- تذكير قبل الموعد بالأيام التي تختارها، وفي يوم التسليم، وبعد تجاوزه.
- أزرار «تم الإنجاز» و«تأجيل ساعة» داخل الإشعار.
- ملخص يومي في الساعة التي تحددها (6–10 صباحاً).
- إعادة جدولة تلقائية بعد إعادة التشغيل أو تحديث التطبيق أو تغيير المنطقة الزمنية.

### التقويم والتقارير
- عرض شهري يبدأ من السبت بنقاط ملوّنة، وعرض أسبوعي بعدد المهام لكل يوم.
- أجندة اليوم المختار وخط زمني للمهام القادمة، مع التاريخ الهجري.
- نسبة الإنجاز، ومعدل الالتزام بالمواعيد، وسلسلة أيام الإنجاز المتتالية.
- توزيع المهام على سبعة أيام قادمة، والإنجاز حسب المشروع، وتنبيه لأثقل الأيام.

### وضع التركيز والإنتاجية
- مؤقت تركيز لكل مهمة (15/25/45/60 دقيقة) تُسجَّل دقائقه على المهمة وفي التقارير.
- أرشيف المهام المكتملة مرتباً حسب الشهر مع بحث.
- إضافة سريعة بسطر واحد من الشاشة الرئيسية: اليوم أو غداً أو بعد أسبوع.

### الاشتراك — مهامي بلس
- نموذج مجاني + بلس: عدد المهام غير محدود مجاناً، والمميزات المتقدمة بالاشتراك.
- ثلاث خطط عبر Google Play Billing: شهري، سنوي، ومدى الحياة (دفعة واحدة).
- شاشة اشتراك بأسعار حية من المتجر، واستعادة مشتريات، وتخزين محلي لحالة الاشتراك
  حتى يعمل التطبيق دون إنترنت.
- التفاصيل والتسعير في [MONETIZATION.md](MONETIZATION.md).

### الويدجت والاختصارات
- ويدجت بأقرب أربع مهام مع إنجاز أي مهمة بضغطة، وويدجت صغير لمهام اليوم.
- اختصارات من أيقونة التطبيق: مهمة جديدة، مهام اليوم، التقويم.

### البيانات والخصوصية
- نسخة احتياطية JSON تصديراً واستيراداً (تشمل المشاريع والخطوات والروابط).
- تصدير إلى التقويم بملف ICS مع تنبيه قبل يوم.
- تقرير نصي جاهز للمشاركة.
- قفل التطبيق ببصمة الجهاز أو رمز القفل.
- وضع فاتح وداكن وحسب النظام، وواجهة عربية كاملة من اليمين إلى اليسار.

## البنية

```
app/src/main/java/com/almarar/mahami/
├── billing/     خطط الاشتراك، حالة الاشتراك المحلية، عميل Google Play Billing
├── core/        التواريخ بالعربية والهجري، الإحصاءات، النسخ الاحتياطي، تصدير CSV و PDF و ICS
├── data/        Room: الكيانات والمحوّلات، DAO، المستودع، القوالب، التفضيلات
├── notify/      قنوات الإشعارات، جدولة المنبهات، مستقبلات النظام، الملخص اليومي
├── widget/      ويدجت Glance وإجراءاته
└── ui/
    ├── theme/       الألوان والخطوط والسمة الفاتحة والداكنة
    ├── components/  البطاقات والمخططات وشريط التنقل وبطاقة المهمة
    └── screens/     إحدى عشرة شاشة
```

## البناء

```bash
# نسخة التطوير
ANDROID_HOME=/path/to/sdk gradle :app:assembleDebug

# حزمة المتجر (تحتاج مفتاح توقيع — انظر RELEASE.md)
ANDROID_HOME=/path/to/sdk gradle :app:bundleRelease
```

المتطلبات: JDK 17، Android SDK 36، Gradle 8.13+.
الحد الأدنى للأندرويد: 8.0 (API 26). الهدف: API 36.
