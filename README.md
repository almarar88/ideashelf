# Chrono AI

منصة توثيق الحياة الفائقة — نموذج واجهة تفاعلي (interactive prototype) مبني بـ
React + TypeScript + Tailwind، يعمل بالكامل داخل المتصفح بلا خادم ولا حساب.

## الهوية

الشعار خط واحد متصل يلتف حلزونياً لفّة ونصف: الزمن حين يُراكم أثراً — حلقات
الشجرة، ودوّامة البصمة، وموجة تتسع من نقطة واحدة. يبدأ من لحظة وينتهي مفتوحاً
عند ما لم يُكتب بعد. مرسوم بضربة واحدة ليبقى مقروءاً عند 24 بكسل، ويُبنى مرة
واحدة في `src/components/ui/Logo.tsx` ثم يُشتق منه أيقونة الويب وأيقونة أندرويد
التكيّفية وشاشة البدء.

## اللغة البصرية

- **الوضع النهاري (Daylight Lavender):** أرضية أرجوانية هادئة، بطاقات بيضاء
  عائمة بزوايا واسعة، وأزرار حبوب — مستوحاة من المرجع البصري المرفق بالطلب.
- **الوضع الليلي (Midnight Obsidian):** سطح OLED عميق كما في المواصفة، مع
  الحفاظ على نفس البنية والتباعد. التبديل من أيقونة القمر/الشمس في الأعلى.
- الواجهة عربية بالكامل واتجاهها RTL، ومصمّمة للهاتف أولاً ثم تتوسّع على
  الشاشات الكبيرة إلى مشهد «جهاز + بطاقات حيّة حوله».

## الشاشات

| الشاشة | ما تفعله |
|---|---|
| **المجرى** | منشورات بعمق قابل للفتح: النص الكامل، الهوامش الموثّقة، محاورة المنشور نفسه، وغربال الحوار الذي يفصل النقاش المُثري عن الضجيج. |
| **الاستوديو** | خط إنتاج الإخراج الآلي: تحليل السياق، إيقاع القص، التصحيح اللوني، إعادة بناء الصوت المكاني، وتوليد لقطة B-Roll لملء الفراغ الزمني. |
| **المقالات** | تفريغ صوتي ← مسوّدة مقال بأسلوبك، مع محرر مرجعي يرصد الأرقام والتواريخ والنسب والأماكن، وتحويل عنقودي إلى بطاقات/سيناريو/حلقة صوتية. |
| **الأطلس** | خريطة حياة ثلاثية الأبعاد + خط زمني + استرجاع سياقي بالوصف لا بالكلمة المفتاحية + تجميع سيرة ذاتية. |
| **الخزنة** | السيادة على البيانات، سجل الأصل الرقمي (C2PA)، والطبقات المعمارية وحالة كل طبقة. |

**زر النبض** في الأسفل ليس زر «+»: وظيفته تتغيّر حسب الشاشة — موجّه إخراج،
مسجّل تفريغ، عدسة تلخيص، استرجاع سياقي، أو ختم أصل رقمي.

## ما هو حقيقي وما هو محاكاة

هذا مهم ومكتوب أيضاً داخل التطبيق نفسه (شاشة الخزنة):

- **حقيقي:** كل المنطق النصي في `src/lib/engine.ts` قواعدي ويعمل فعلاً —
  تنقية الحشو، بناء الفقرات، قياس بصمة النبرة، كشف الوقائع القابلة للتحقق
  (تواريخ/نسب/أرقام/أماكن)، التحويل بين القوالب، الاسترجاع بالمطابقة اللغوية،
  غربال التعليقات، وإجابات محاورة المنشور من بياناته الوصفية.
- **محاكاة:** لا يوجد نموذج لغوي ولا رؤية حاسوبية خلف الاستوديو أو الصياغة.
  خط إنتاج الإخراج عرض زمني لمراحل مصمّمة، وأرقامه مشتقة من مدخلاتك.
- **تصميم معماري لم يُنفّذ بعد:** التشفير صفري المعرفة، توقيع C2PA الفعلي،
  المعالجة على الجهاز، ومحرك RAG.
- **لا صور لأشخاص:** كل الوسائط مولّدة رياضياً (تدرّجات + ضوضاء SVG)، فلا
  حقوق طرف ثالث ولا طلبات شبكة للصور.

## تطبيق أندرويد (APK)

التطبيق مغلّف بـ Capacitor، والمشروع الأندرويدي داخل `android/`.

```bash
npm run android:apk     # ينتج android/app/build/outputs/apk/debug/app-debug.apk
```

لبنائه من غير جهازك: ادفع الفرع، وworkflow المسمّى **Build Android APK**
يبنيه ويرفعه كملف قابل للتحميل من صفحة Actions.

الملف المُنتَج موقّع بمفتاح التصحيح (debug) — يُثبَّت مباشرة بعد السماح
بـ«تثبيت من مصدر غير معروف»، لكنه غير صالح للرفع على Google Play؛ ذلك يحتاج
مفتاح إصدار خاص بك لا يُشارك في المستودع.

## دعم الأجهزة القابلة للطي

التخطيط يتبدّل حسب شكل النافذة فعلياً، لا حسب نوع الجهاز:

| الحالة | التخطيط |
|---|---|
| الشاشة الخارجية أو هاتف عادي (أقل من 600px) | لوحة واحدة، شريط تنقل سفلي |
| الشاشة الداخلية مفتوحة (600–1180px) | لوحتان: القائمة يميناً والعمق يساراً، وشريط تنقل رأسي |
| ممتدة عبر المفصلة | اللوحتان تنطبقان على جزأي الشاشة، والفاصل يقع على المفصلة نفسها |
| وضع الطاولة (مفصلة أفقية) | لوحة فوق وأخرى تحت |
| سطح مكتب واسع | عرض الجهاز داخل لوحة مع البطاقات الحيّة |

الفجوة عند المفصلة محسوبة من `env(viewport-segment-*)`، فلا ينقسم أي محتوى
على المفصلة. وعلى جانب أندرويد، `resizeableActivity` و`supportsSizeChanges`
و`configChanges` تمنع إعادة تشغيل التطبيق عند الفتح أو الطي — ينتقل التخطيط
بين لوحة ولوحتين مع بقاء الحالة كما هي.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173/ideashelf/
npm run build    # إخراج الإنتاج في dist/
npm run preview
```

الخط العربي (IBM Plex Sans Arabic) يُحمَّل من Google Fonts؛ إن تعذّر الوصول
للشبكة تعود الواجهة تلقائياً إلى خطوط النظام دون كسر التخطيط.
