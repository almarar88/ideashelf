# مكتبة الكود الرقمية

مكتبة إلكترونية مدعومة بالذكاء الاصطناعي: ارفع كتبك بصيغة PDF، اقرأها، ثم لخّصها وحلّلها واسألها بالذكاء الاصطناعي (Claude). تعمل كتطبيق ويب (PWA) وكتطبيق أندرويد (APK) مع دعم الأجهزة القابلة للطي.

## المزايا

- **قارئ PDF** مدمج (pdf.js) يفتح الكتاب على **ملء الشاشة** مباشرة (تظهر الأدوات لحظتين ثم تنزاح)، مع وضعَي عرض: **الصفحة كاملة** و**ملء العرض**، وتكبير بالقرص أو النقر المزدوج، وشريط انتقال سريع، وحفظ موضع القراءة.
- **تأثير تقليب صفحة حقيقي**: الصفحة تُرفع وتدور ثلاثيًا حول الكعب الأيمن (اتجاه الكتاب العربي) بمنظور، مع ظل يسقط على الصفحة تحتها ويتتبّع حافة الورقة المرفوعة، وظهر ورقي للصفحة أثناء انقلابها. الصفحات المجاورة تُرسم مسبقًا في ذاكرة مؤقتة فيبدأ التقليب فورًا بلا انتظار. يمكن اختيار **انزلاق** أو **بدون تأثير** من الإعدادات.
- **دعم كامل للنصوص العربية**: تُرسم الصفحة على لوحة بـ `direction: ltr` لأن وراثة اتجاه RTL تجعل المتصفح يعيد ترتيب الحروف المرسومة مسبقًا فيكسر الكلمات. كما يُعاد بناء نص كل سطر من إحداثيات الحروف (ترتيب من اليمين لليسار، مسافات من الفجوات الحقيقية، وتحويل أشكال العرض `Presentation Forms` إلى حروف أساسية) بدل قراءة `getTextContent` مباشرة التي تعطي حروفًا مقلوبة ومتباعدة في الكتب العربية.
- **ذكاء اصطناعي** على مستوى الصفحة، أو نطاق صفحات، أو الكتاب كاملاً: تلخيص، تحليل عميق، شرح مبسط، اختبار، ومحادثة مع الكتاب مع ذكر أرقام الصفحات. الكتب الطويلة جدًا تُعالج على مراحل (map-reduce).
- **تحديث تلقائي لنص الكتب القديمة**: لكل كتاب رقم إصدار لطريقة استخراج النص. الكتب التي أُضيفت قبل إصلاح قراءة العربية يُعاد استخراج نصها في الخلفية عند فتحها، مع زر يدوي في لوحة المشرف.
- **تخزين محلي كامل** (IndexedDB): الكتب، النص المستخرج، النتائج، والمحادثات تبقى على الجهاز وتعمل بلا إنترنت.
- **تحليل القراءة**: دقائق القراءة أسبوعيًا/شهريًا واستخدام كل كتاب.
- **لوحة تحكم المشرف** (تسجيل دخول باسم مستخدم وكلمة مرور): رفع كتب بالجملة، **نشر كتاب PDF لجميع المستخدمين** مباشرة إلى المستودع عبر GitHub API (يرفع الملف إلى `public/library/` ويحدّث `public/catalog.json`)، تعديل/حذف الكتب، تصدير/استعادة نسخة احتياطية، مسح البيانات.
  - بيانات الدخول مخزنة كبصمة SHA-256 في `src/lib/admin.ts`. لتغييرها: `node -e "console.log(require('crypto').createHash('sha256').update('dcl-admin:USER:PASS').digest('hex'))"` وضع الناتج في `ADMIN_HASH`.
  - تنبيه: التطبيق بلا خادم، فهذه الحماية تمنع الوصول العابر فقط ولا تُعد أمانًا حقيقيًا. رمز GitHub للنشر يُحفظ محليًا على جهاز المشرف فقط.
- **تصميم متجاوب**: عمود واحد على الهاتف، وعرض مزدوج (القارئ + لوحة الذكاء الاصطناعي) عند فتح الجهاز القابل للطي أو على الأجهزة اللوحية.

## المنصة: حسابات ومتجر واشتراكات

التطبيق يعمل بوضعين في بناء واحد:

- **بدون خادم**: يرفع القارئ ملفاته ويقرأها ويحللها، وكل شيء على جهازه. هذا هو السلوك إذا لم تُضبط متغيرات Supabase.
- **مع خادم**: تظهر تبويبة **المتجر** والحسابات والاشتراكات ومزامنة القراءة.

### تشغيل وضع المنصة

١. أنشئ مشروعًا على supabase.com.
٢. انسخ `.env.example` إلى `.env` واملأ `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.
٣. طبّق المخطط: `npx supabase link --project-ref <ref>` ثم `npx supabase db push`.
٤. انشر الدوال: `npx supabase functions deploy verify-purchase delete-account`.
٥. اجعل حسابك مشرفًا: نفّذ في محرر SQL `update public.profiles set role = 'admin' where email = 'بريدك';`
٦. من التطبيق: الإعدادات ← لوحة تحكم المشرف ← **نشر كتاب** ← نشر في المتجر.

### الكتاب الصوتي

صوت عربي طبيعي يقرأ كتب المتجر صفحة صفحة وينتقل تلقائيًا. الصوت يُولَّد مرة واحدة لكل صفحة
ويُخزَّن ويُعاد استخدامه لكل المستمعين، لأن ElevenLabs تحاسب بعدد الحروف: التكلفة على الكتاب
لا على القارئ.

```bash
npx supabase secrets set ELEVENLABS_API_KEY=... ELEVENLABS_VOICE_ID=...
npx supabase functions deploy narrate voices
```

النموذج الافتراضي `eleven_flash_v2_5` (يدعم العربية وسعره نحو نصف النماذج القياسية). يمكن
اختيار الصوت والسرعة من الإعدادات، وحصة الحروف الشهرية لكل مستخدم تُضبط بـ `TTS_MONTHLY_CHARS`.

ملف الصوت محمي بنفس قاعدة الصفحات: حاوية خاصة، ورابط موقّع لا يُمنح إلا لمن يحق له قراءة
الصفحة.

الكتب التي يرفعها القارئ بنفسه تُقرأ بمحرّك النطق الأصلي في أندرويد عبر
`@capacitor-community/text-to-speech`، بلا تكلفة وبلا إنترنت. **واجهة `speechSynthesis` في
المتصفح لا تعمل داخل WebView**، ولهذا يستخدم التطبيق الإضافة الأصلية على الهاتف ويحتفظ
بواجهة المتصفح لنسخة الويب فقط. إن لم تكن حزمة النطق العربية مثبّتة يظهر زر يفتح شاشة
تثبيتها في أندرويد.

**أذونات أندرويد**: تطلب النسخة إذن الإشعارات (أندرويد ١٣+) لأن إخفاءه يُلغي أزرار التحكم،
وتستخدم `FOREGROUND_SERVICE_MEDIA_PLAYBACK` (أندرويد ١٤+).

**أين تجد الميزة**: زر السماعة في شريط القارئ العلوي، أو شريط «استماع للكتاب» أسفل الشاشة،
أو من قائمة الكتاب في «مكتبتي» ← «استمع للكتاب» فيبدأ التشغيل مباشرة.

**قراءة متصلة بلا يدين**: عند انتهاء الصفحة ينتقل التطبيق للتالية ويكمل القراءة حتى آخر
الكتاب. وتبقى الشاشة مضاءة أثناء القراءة عبر `@capacitor-community/keep-awake`، لأن أندرويد
يوقف تنفيذ JavaScript في WebView عند نوم الجهاز فتتوقف القراءة بين المقاطع.

**القراءة في الخلفية**: على أندرويد تعمل القراءة داخل **خدمة أمامية**
(`AudiobookService`) لا داخل صفحة الويب، لأن أندرويد يوقّف تنفيذ JavaScript في WebView عند
نوم الجهاز. النتيجة أن الكتاب يستمر في القراءة والشاشة مطفأة أو التطبيق في الخلفية، مع
**أزرار تحكم في شريط الإشعارات وشاشة القفل**: تشغيل، إيقاف، الصفحة التالية والسابقة.

الخدمة تستقبل صفحات الكتاب دفعة واحدة عند بدء التشغيل، لأن طبقة الويب لن تكون متاحة
لسؤالها عن الصفحة التالية بعد أن ينام الجهاز. لكتبك الخاصة تُرسل نصوص الصفحات كلها؛ ولكتب
المتجر تُرسل روابط صوت موقّعة صالحة ساعة، وتُمدَّد النافذة كلما كان التطبيق مفتوحًا.

تحترم الخدمة سلوك مشغّلات الصوت: تتوقف عند ورود مكالمة (Audio Focus)، وعند نزع السماعة،
وتستأنف من الإشعار. والخروج من الكتاب يوقف القراءة؛ أما إخفاء التطبيق فيبقيها تعمل.

### كيف تُحمى الكتب

ملف PDF لا يُرفع إلى الخادم إطلاقًا. عند النشر تُحوَّل كل صفحة إلى صورة ويُستخرج نصها، وتُخزَّن الصور في حاوية خاصة. القارئ يحصل على **رابط موقّع صالح خمس دقائق لكل صفحة**، ولا يُمنح الرابط إلا بعد أن تتحقق قاعدة البيانات من أنه اشترى الكتاب أو أن اشتراكه ساري. تُطبع على كل صفحة علامة مائية ببريد القارئ، ويمنع `FLAG_SECURE` لقطات الشاشة على أندرويد.

هذه الحماية مُختبَرة: ٢٤ اختبارًا تتحقق من أن قارئًا غير مشترٍ يرى صفحات المعاينة فقط، ولا يستطيع الحصول على رابط لصفحة مقفلة، ولا يستطيع منح نفسه ملكية كتاب. شغّلها بـ `node` على قاعدة محلية عبر `npx supabase start`.

**لا يوجد منع مطلق للنسخ.** أي محتوى يُعرض يمكن تصويره بكاميرا. الهدف رفع كلفة السرقة وجعل المسرَّب متتبَّعًا، لا الوعد بالمستحيل.

## مفتاح الذكاء الاصطناعي

التطبيق يعمل بدون خادم وسيط. أدخل مفتاح Anthropic API من `الإعدادات`؛ يُحفظ على جهازك فقط ويُرسل مباشرة إلى `api.anthropic.com`. النموذج الافتراضي `claude-opus-5` ويمكن اختيار Sonnet 5 أو Haiku 4.5.

## التشغيل محليًا

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # إخراج dist/ (base = ./)
npm run build:pages  # إخراج dist/ لـ GitHub Pages (base = /ideashelf/)
```

## أندرويد (APK)

المشروع مغلّف بـ Capacitor 7. متطلبات: JDK 21 + Android SDK (platform 35).

```bash
npm run apk        # build + cap sync + gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

نسخة جاهزة للتثبيت موجودة في `release/digital-code-library-debug.apk`، وعملية `Build Android APK` في GitHub Actions تبني APK عند كل دفع إلى `main` وترفقه بالإصدار عند الوسم `v*`.

**دعم الأجهزة القابلة للطي:** النشاط معلَّم `resizeableActivity="true"` ويتعامل مع تغييرات `screenSize|smallestScreenSize|screenLayout|density` دون إعادة إنشاء، والواجهة تتبدل تلقائيًا بين تخطيط الهاتف والتخطيط المزدوج عند الطي/الفتح مع الحفاظ على الحالة.

## الفهرس العام للكتب

ضع ملفات PDF في `public/library/` وأضفها إلى `public/catalog.json`:

```json
{ "books": [ { "id": "clean-code", "title": "Clean Code", "author": "Robert C. Martin", "url": "./library/clean-code.pdf", "tags": ["برمجة"] } ] }
```

بعد النشر يستطيع أي مستخدم تنزيلها من لوحة المشرف ← الفهرس العام.

- `src/screens/` الشاشات: Home, Library, Reader, AIPanel, Insights, Settings, Admin, Onboarding
