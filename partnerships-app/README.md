# شريك | PartnerHub — تطبيق أندرويد لإدارة الشراكات ودراسات الجدوى بالذكاء الاصطناعي

تطبيق أندرويد (React + Capacitor) بتصميم "الزيتوني الداكن" الموضّح في النموذج: بطاقات بيضاء ودُكنة بحواف دائرية، شريط أيام، أولويات (عاجل/متوسط/عادي)، وخلفية طوبوغرافية. يدعم العربية (RTL) والإنجليزية، الهواتف العادية والقابلة للطي (تخطيط جانبي وعرض رئيسي/تفصيلي عند فتح الشاشة).

## المميزات

**قسم الشراكات**
- سجل الشركاء (CRM): أنواع (استراتيجي، راعٍ، مورّد، حكومي، غير ربحي، أكاديمي، إعلامي، تقني)، جهات اتصال، وسوم، روابط/مرفقات، ملاحظات، ودرجة "صحة" محسوبة تلقائياً من آخر تواصل والفرص المتعثرة والالتزامات.
- مسار الفرص (Pipeline): مراحل من الفرصة حتى التوقيع والتجديد، احتمالية وقيمة مرجّحة، رصد الفرص المتعثرة.
- الاتفاقيات: مذكرات تفاهم/عقود/رعاية/NDA/SLA، تنبيهات انتهاء ومهلة الإشعار، تتبع الالتزامات لكل طرف، ومراجعة البنود بالذكاء الاصطناعي.
- المهام اليومية بشريط الأيام (كما في التصميم)، الاجتماعات مع تلخيص المحاضر واستخراج بنود العمل، التقويم الموحّد (مهام + إغلاق فرص + انتهاء اتفاقيات + اجتماعات)، بحث شامل، تقارير ولوحات، تنبيهات محلية للمهام والتجديدات.

**دراسات الجدوى (AI)**
- معالج من 3 خطوات → دراسة كاملة: ملخص تنفيذي، سوق، فني، قانوني، تشغيلي، مالي، SWOT، سجل مخاطر ومصفوفة، نماذج شراكة مقترحة، تقييم بالدرجات، توصية GO/مشروط/NO-GO، خطوات تالية ومؤشرات أداء.
- محرك مالي محلي وقابل للتحقق: NPV، IRR، فترة الاسترداد، نقطة التعادل، ROI، مع تحليل حساسية تفاعلي (الإيرادات/التكاليف/رأس المال/معدل الخصم).
- مقارنة الدراسات، تحويل الخطوات إلى مهام، مطابقة الشركاء الأنسب للدراسة.

**الوكيل الذكي (موجود في كل الشاشات)**
- زر الوكيل ثابت في كل شاشة + يعرف السياق الحالي (الشريك/الدراسة المفتوحة).
- ينفّذ مهامًا فعلياً عبر أدوات: إنشاء مهام/شركاء/فرص/اتفاقيات/اجتماعات، نقل المراحل، تسجيل التواصل، بدء دراسات جدوى، توليد مستندات، وتصدير ملفات.
- قائمة "مهام الوكيل": كلّفه بمهمة نصية وتابع خطوات التنفيذ والنتيجة. يمكن تكليف الوكيل بأي مهمة من نموذج المهمة (✦ تكليف الوكيل).

**التصدير**
- Excel (xlsx) للشركاء/المسار/المهام/الاتفاقيات/الاجتماعات/النموذج المالي للدراسة.
- Word (docx) و PDF لدراسات الجدوى، التقارير الأسبوعية، عروض الشراكة، ملفات الشركاء، ومحاضر الاجتماعات.
- على أندرويد تُحفظ الملفات في `Documents/PartnerHub` وتُفتح نافذة المشاركة مباشرة.

## الذكاء الاصطناعي
يعمل بمفتاح Anthropic API خاص بالمستخدم (يُحفظ على الجهاز فقط) — الإعدادات ← مفتاح API. النموذج الافتراضي `claude-opus-5` مع تفعيل الرجوع التلقائي (server-side fallbacks). بدون مفتاح يعمل التطبيق بوضع تجريبي مُعلَّم بوضوح.

## التشغيل والبناء
```bash
cd partnerships-app
npm install
npm run dev            # تجربة في المتصفح
npm run build && npx cap sync android
cd android && ./gradlew assembleDebug   # ينتج app/build/outputs/apk/debug/app-debug.apk
```
أو افتح `android/` في Android Studio. كما يوجد GitHub Action يبني الـ APK تلقائياً عند كل دفع (Artifacts → partnerhub-debug-apk).

ملاحظة: الـ APK الحالي نسخة تطوير (debug). للنشر على Google Play يلزم توقيع إصدار release بمفتاح خاص.
