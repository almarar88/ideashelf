# مهامي — تطبيق أندرويد لإدارة المهام والمواعيد

تطبيق أندرويد أصلي (Kotlin + Jetpack Compose) لعرض المهام وتفاصيلها ومواعيد تسليمها،
مع تقويم شهري، وتقارير، وتنبيهات، وويدجت على الشاشة الرئيسية. الواجهة عربية بالكامل
واتجاهها من اليمين إلى اليسار.

## الشاشات

| الشاشة | المحتوى |
|---|---|
| الترحيب | ثلاث شرائح تعريفية (نظرة عامة، التنبيهات، الويدجت) |
| الرئيسية | تحية باسم المستخدم، بطاقة أقرب موعد تسليم مع العدّ التنازلي، بطاقات إحصائية (اليوم/مكتملة/متأخرة)، نسبة الإنجاز، الملاحظات والتوصيات، المهام القادمة |
| المهام | بحث، تصفية (الكل/اليوم/قادمة/متأخرة/مكتملة)، ترتيب (الموعد/الأولوية/الإنجاز) |
| التقويم | شبكة شهرية تبدأ من السبت مع نقاط ملوّنة لكل مهمة، أجندة اليوم المختار، وخط زمني للمهام القادمة، مع التاريخ الهجري |
| التقارير | مؤشر قوسي لنسبة الإنجاز، توزيع أسبوعي بأعمدة، مؤشرات الحالة، الإنجاز حسب الجهة، وأثقل الأيام، مع مشاركة التقرير كنص |
| تفاصيل المهمة | المطلوب، جهة المتابعة، الخطوات القابلة للتأشير، الملاحظات، التنبيهات، تنبيه الأخطاء المحتملة، مشاركة، تعديل، حذف |
| إضافة/تعديل | العنوان، التفاصيل، الجهة، المتابعة، التاريخ والوقت، الأولوية، التكرار، مواعيد التنبيه، الخطوات، الملاحظات |
| المساعد الذكي | محادثة تعرف مهامك، خطة اليوم، كشف المخاطر والتعارضات، الملخص الأسبوعي |
| الإضافة الذكية | لصق رسالة أو محضر اجتماع وتحويله إلى مهام بمواعيدها وخطواتها قبل الحفظ |
| الإعدادات | الاسم، التنبيهات، الملخص اليومي، الوضع الليلي، مفتاح Claude والنموذج واختبار الاتصال، النسخ الاحتياطي، تصدير التقويم |

## المهام المُحمّلة مسبقاً

المهام الخمس مرتّبة حسب الموعد النهائي، وكل واحدة مقسّمة إلى خطوات:

1. **خطة زمنية للتواصل مع الجهات الحكومية** — الاثنين 14-09-2026
2. **حصر مناهج دورات تعليم اللغات** — الثلاثاء 15-09-2026 (أ. منى الكندي)
3. **مقترح طرح دورات اللغات في الربع الرابع** — الأربعاء 16-09-2026
4. **استكمال ملفات المدربين** — الأربعاء 16-09-2026 (أ. آسيا الربيعي) — مع تنبيه داخل المهمة إلى أن تاريخ 23-08-2026 الوارد في الرسالة يوم أحد وقد مضى، والأرجح أنه 16-09-2026
5. **اجتماع تطوير منصة التسجيل** — موعد مرن ضمن 14–18 سبتمبر 2026

والملاحظات الأربع (خطأ التاريخ، ضغط الأربعاء، اتصال منصة التسجيل، التقرير المرفق)
تظهر كبطاقات في الشاشة الرئيسية.

## المميزات الذكية

تعمل بطبقتين: **Claude** عند إدخال مفتاح Anthropic API من الإعدادات، و**محرك محلي**
يعمل دون إنترنت ودون مفتاح. كل نتيجة تُوسم بمصدرها، وإذا تعذّر الاتصال يسقط التطبيق
تلقائياً إلى المحرك المحلي بدل أن يفشل.

| الميزة | مع Claude | بدون مفتاح (محلي) |
|---|---|---|
| استخراج مهام من نص | فهم كامل للرسالة مع خطوات وتصنيف وأولوية | تقسيم النص، وقراءة التواريخ العربية (16-09-2026، الأربعاء القادم، بعد أسبوع، ١٤-٠٩-٢٠٢٦)، واستخراج اسم المتابع والأولوية |
| خطة اليوم | ترتيب مُعلَّل حسب ضغط المواعيد والاعتماديات | ترتيب بخوارزمية وزن الموعد والأولوية والاعتماد على ردود الآخرين |
| المخاطر والتعارضات | مراجعة شاملة للقائمة | ازدحام اليوم الواحد، التأخّر، المواعيد المرنة، ما لم يبدأ رغم قرب موعده |
| اقتراح خطوات لمهمة | خطوات من واقع تفاصيل المهمة | قوالب حسب نوع المهمة (اجتماع، خطة، حصر وثائق، تقرير) |
| صياغة رسالة متابعة | رسالة رسمية أو قصيرة جاهزة للإرسال | مسودة رسمية بالموعد والمطلوب |
| الملخص الأسبوعي | تقرير موجز يصلح للإرسال لرئيس القسم | ملخص رقمي بالمنجز والمستحق والمتأخر |
| محادثة حرة | أي سؤال عن المهام | إجابات عن: خطة اليوم، المتأخر، المخاطر، الملخص |

النماذج المتاحة: Claude Sonnet 5 (افتراضي)، Opus 5، Haiku 4.5.
يُحفظ المفتاح مشفّراً عبر Android Keystore (`EncryptedSharedPreferences`) على الجهاز فقط،
ولا يُرسل إلا إلى `api.anthropic.com`. لا يوجد خادم وسيط للتطبيق.

## أدوات إضافية

- **تكرار المهام**: عند إنجاز مهمة متكررة (يومي/أسبوعي/شهري) تُنشأ نسختها التالية تلقائياً.
- **تأجيل سريع**: يوم، ثلاثة أيام، أو أسبوع بضغطة من شاشة المهمة.
- **نسخة احتياطية**: تصدير واستيراد كل المهام بصيغة JSON.
- **تصدير إلى التقويم**: ملف ICS يفتح في تقويم جوجل أو أبل أو أوتلوك، مع تنبيه قبل يوم.

## التنبيهات

- تنبيه لكل مهمة قبل موعدها بالأيام المحددة (افتراضياً 3 و1 ويوم التسليم) عبر `AlarmManager`
  بمنبهات دقيقة، الساعة 8 صباحاً للتنبيهات المبكرة وفي وقت التسليم ليوم الموعد.
- تنبيه متابعة صباح اليوم التالي عند تجاوز الموعد.
- أزرار داخل الإشعار: **تم الإنجاز** و**تأجيل ساعة**.
- ملخص يومي عبر `WorkManager` في الساعة التي يختارها المستخدم (6–10 صباحاً).
- إعادة الجدولة تلقائياً بعد إعادة تشغيل الجهاز أو تحديث التطبيق أو تغيير الوقت.

## الويدجت

ويدجت مبني على Glance يعرض أقرب أربع مهام مع تواريخها وحالتها (متأخرة/اليوم/قادمة)
وعدّاد الإنجاز، ويسمح بإنجاز أي مهمة بالضغط على دائرتها، ويفتح التطبيق عند الضغط عليه.
لإضافته: ضغط مطوّل على الشاشة الرئيسية ← Widgets ← مهامي.

## البناء

```bash
cd android
ANDROID_HOME=/path/to/sdk gradle :app:assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

المتطلبات: JDK 17+، Android SDK 34، Gradle 8.x.
الحد الأدنى للأندرويد: 8.0 (API 26).

## البنية

```
app/src/main/java/com/almarar/mahami/
├── ai/          محرك Claude، المحرك المحلي، تخزين المفتاح مشفّراً
├── data/        Room: الكيانات، DAO، المستودع، البيانات الأولية، التفضيلات
├── notify/      قنوات الإشعارات، جدولة المنبهات، مستقبلات البث، عامل الملخص اليومي
├── widget/      ويدجت Glance وإجراءاته
├── ui/
│   ├── theme/       الألوان، الخطوط (Tajawal)، السمة الفاتحة والداكنة
│   ├── components/  البطاقات الناعمة، المخططات، شريط التنقل، بطاقة المهمة
│   └── screens/     الشاشات الثماني
└── util/        تنسيق التواريخ بالعربية والهجري، شبكة التقويم، النسخ الاحتياطي و ICS
```

الخط المستخدم: Tajawal بترخيص SIL OFL — نسخة الترخيص في `THIRD_PARTY_LICENSES/`.
