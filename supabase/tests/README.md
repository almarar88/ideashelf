# اختبارات الصلاحيات

`rls.mjs` يتحقق من أن قواعد قاعدة البيانات تمنع فعلاً ما يجب منعه: قارئ لم يشترِ لا يرى
إلا صفحات المعاينة، ولا يحصل على رابط لصفحة مقفلة، ولا يستطيع منح نفسه ملكية كتاب.

```bash
npx supabase start          # قاعدة محلية
npx supabase db reset       # تطبيق المخطط
npm i @supabase/supabase-js # إن لم تكن مثبتة
node supabase/tests/rls.mjs # 18 اختبارًا
```

المفاتيح في الملف هي مفاتيح البيئة المحلية الثابتة من Supabase CLI، وليست أسرارًا.
